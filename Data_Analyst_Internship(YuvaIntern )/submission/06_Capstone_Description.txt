This report addresses Task 6, Final Data Science Capstone Project, in the Data Analyst internship. This project uses the real diabetes cohort distributed with scikit-learn. There are 442 records, ten baseline predictors and one quantitative progression target measured one year after baseline. Raw predictor values are loaded with scaled=False. The scope is educational data analysis and regression, rather than diagnosis or treatment. The same traceable source supports the practical internship tasks, while each report addresses a different objective. The capstone builds a benchmark regression solution and evaluates it against a mean baseline. Deliverables include preparation, EDA, model comparison, held-out predictions, residual plots and stakeholder recommendations. Load the real cohort with sklearn.datasets.load_diabetes and export raw units. Audit missing values, duplicates and outliers without manufacturing source defects. Preserve valid extreme values. Use the ten existing predictors without additional engineered features for an interpretable benchmark. Pipeline scaling is learned from training subsets only. An 80/20 split uses random_state 42, yielding 353 training and 89 test records. Compare a mean baseline, linear regression, ridge with alpha 10, and a random forest with 200 trees and minimum leaf size 5. Five shuffled training folds use mean absolute error for selection. This prevents choosing the algorithm based on its final test result. Hyperparameter optimization is outside scope.

Use this result as an educational baseline. Add repeated or nested cross-validation if optimizing parameters, inspect subgroup error, and assess independent data before changing scope. Consider prediction intervals and compare alternative models using an agreed protocol. Document any future feature engineering so it remains fitted within training folds. Run python run_all.py to regenerate CSVs, charts and evaluation. Notebook 06 explains the comparison and displays prediction errors. The HTML presentation in presentation/capstone_presentation.html summarizes the problem, methodology, findings and limitations. Environment versions are recorded in outputs/results.json.
