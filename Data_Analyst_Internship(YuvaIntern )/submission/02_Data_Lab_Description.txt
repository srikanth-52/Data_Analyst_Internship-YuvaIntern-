This report addresses Task 2, Hands On Data Lab Implementation, in the Data Analyst internship. The lab establishes a reproducible Python workspace and demonstrates data loading, manipulation, cleaning, visualization and summary analysis. Use Python 3.10 or newer, create a virtual environment and install requirements.txt. Start Jupyter from the extracted project folder and open notebook 02. Windows commands are python -m venv .venv, .venv\Scripts\activate, python -m pip install -r requirements.txt, python run_all.py and jupyter notebook. On Linux or macOS use source .venv/bin/activate. The bundled CSV supports offline reruns after dependency installation. outputs/results.json records the executed package versions. Load the CSV with pandas.read_csv, inspect shape and dtypes, compute describe, filter BMI above 30 and summarize target scores. Use NumPy for mean, median and standard deviation; use Pandas for filtering, groupby and CSV export. Plot a histogram and scatter chart with Matplotlib and label axes with the actual variables.

The full audited data contain 442 rows and 11 columns. The mean target is 152.1335 and median target is 140.5. Compare before and after row counts for the lab copy and confirm the full source is not overwritten. Exported clean and dirty examples make transformations reviewable. Notebook 02 and src/analysis.py provide the implementation. data/lab_dirty_example.csv and lab_clean_example.csv hold the cleaning evidence. The lab produces labelled charts and reusable tabular outputs, establishing a working environment for subsequent tasks.
