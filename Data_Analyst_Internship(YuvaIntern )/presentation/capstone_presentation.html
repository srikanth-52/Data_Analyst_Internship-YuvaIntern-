Problem and scope

This project uses the real diabetes cohort distributed with scikit-learn. There are 442 records, ten baseline predictors and one quantitative progression target measured one year after baseline. Raw predictor values are loaded with scaled=False. The scope is educational data analysis and regression, rather than diagnosis or treatment. The same traceable source supports the practical internship tasks, while each report addresses a different objective.

Evaluation protocol

353 training records and 89 held-out records. Compare four models using five training folds. Select by training MAE, then evaluate the chosen model once on the test split.
